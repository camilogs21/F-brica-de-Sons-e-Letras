Fase 2: Decifrar os Algoritmos Lógicos 💻

Demonstre seu domínio em Engenharia de Software associando os conceitos e comportamentos corretos.

1. O que representa uma Variável dentro do ecossistema Incredibox?
✨ Excelente! Cada personagem funciona guardando um dado mutável (o som ativo).
2. O que representa o conceito de Array na estrutura da batida?
✨ Corretíssimo! Array é uma estrutura de lista que organiza múltiplos dados (sons) juntos.
3. O que representa o mecanismo de Loop na execução musical?
✨ Certo! Loops executam blocos de código repetidamente enquanto uma condição for verdadeira.
4. O que representa uma Condicional (if/else) nessa atividade?
✨ Fantástico! "SE" ícone estiver no personagem, toque o som; "SENÃO", fique em silêncio.
5. Do ponto de vista de sistemas, o que ocorre se removermos um personagem da batida?
✨ Perfeito! Limpar o avatar redefine o valor da variável e altera a saída do programa.
